# Project title

Write a short opening paragraph that explains what the model does, where it is
used, and the practical problem it solves.

## Highlights

- Lead with the most useful design choices.
- Mention capacity, fit, modularity, or printability.
- Include meaningful dimensions rather than marketing language.

## Dimensions

Add a compact table for the overall size and critical fit dimensions.

## Files

- `src/example.scad` — editable source and important parameters.
- `files/example.3mf` — printable export.
- Explain quantities when a file must be printed more than once.

## Recommended print settings

- Material
- Layer height
- Walls
- Infill
- Supports
- Brim or adhesion notes
- Required orientation

Only call a model support-free after checking the actual overhangs or slicer
preview.

## Assembly and use

Give the shortest complete sequence from printed parts to a working object.
Include required hardware and fit checks.

## Customization

List the most useful source parameters and what changing them affects.

## Validation and limitations

State what was rendered, sliced, printed, fitted, or load-tested. Clearly
separate digital validation from physical validation.
